# curio-taste-catalog

A self-hosted Stremio/Nuvio addon that serves AI-curated movie and series rows built from your own taste: Letterboxd exports and RSS, Simkl watch history, and friends' feeds. Generation runs as a LangGraph agent in a background worker; the catalog endpoints Nuvio calls never touch an LLM.

Status: planning. See the [milestones](https://github.com/1-Archit-1/curio-taste-catalog/milestones) and [issues](https://github.com/1-Archit-1/curio-taste-catalog/issues).

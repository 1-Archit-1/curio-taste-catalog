API Keys

Trust & key safety notice: Stored API keys are encrypted with a public key so the API process cannot read them, and decrypted only by background workers during generation. However, the server operator can technically access stored keys (you can self-host Curio from the public repository if you prefer not to share keys). We strongly advise creating a dedicated Gemini API key restricted to the Gemini API with a quota cap in Google Cloud — and similarly using dedicated, spend-capped keys for OpenAI, Anthropic, or OpenRouter.
